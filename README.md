# Datenschutzerklärung - EP Bundesland Kalender

**Entwickler:** EP Software

## 1. Grundsatz (Local-First)
Der Schutz deiner persönlichen Daten hat höchste Priorität. Der „EP Bundesland Kalender“ ist als rein lokale Anwendung (Local-First-Architektur) konzipiert. Sämtliche von dir eingegebenen Daten (wie Termine, Urlaube und Einstellungen) werden ausschließlich lokal auf deinem eigenen Endgerät (im Speicher der App bzw. im `localStorage`) gesichert.

## 2. Keine Datenerhebung
Es werden zu keinem Zeitpunkt personenbezogene Daten, Nutzungsstatistiken oder Standortdaten an den Entwickler oder an externe Server übertragen. Die App benötigt keine Registrierung und kommt ohne Cloud-Speicher aus.

## 3. Berechtigungen der App
Die App benötigt gegebenenfalls bestimmte Berechtigungen (wie Benachrichtigungen oder den Zugriff auf den Speicher für den Export von `.ics`-Dateien), die jedoch ausschließlich lokal auf deinem Gerät für die Kernfunktionen verwendet werden.

## 4. Lokale Backups und Datenaustausch
Du hast die Möglichkeit, deine Kalenderdaten manuell als `.ics`-Datei zu exportieren oder zu importieren. Diese Dateien werden von dir selbst verwaltet; es findet keine automatische Übertragung in ein externes Netzwerk statt.

## 5. Kontakt
Bei Fragen zum Datenschutz kannst du dich direkt an den Entwickler wenden.
